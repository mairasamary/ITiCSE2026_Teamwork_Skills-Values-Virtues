# Phase 1 — Screening Tables

Place the Phase 1 screening exports here: the IN, OUT, Discussion, and Judging tables described in [`../extraction/screening-tool-documentation.md`](../extraction/screening-tool-documentation.md).

Suggested files:

- `in.csv` — papers both reviewers agreed to include
- `out.csv` — papers both reviewers agreed to exclude
- `discussion.csv` — papers reviewers disagreed on, prior to judging
- `judging.csv` — Discussion papers with a third-party judge's decision
- `master_corpus_metadata.csv` — the full ~10,987-paper metadata list (title, authors, DOI, venue, etc. — without the papers' actual full text/PDFs)
