# Appendix 1 — Screening Tool Screenshots

Screenshots of the tool used to select papers in Phase 1 of the systematic literature review.

Each reviewer selected the pair they belonged to for the batch of papers they had to review in Phase 1. Pairs could be at different points in the process, since reviewers worked through their assignments at different paces — a reviewer was only assigned more papers once their previous assignment was finished.

From the pair selection, each person then identified themselves individually. The tool then showed each reviewer the papers for that pair in alphabetical order by title, with a clear separation between papers still to be done and papers already completed (shown under "Already reviewed").
