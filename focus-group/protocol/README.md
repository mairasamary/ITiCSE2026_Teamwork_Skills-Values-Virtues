# Focus Group Protocol

- [`focus-group-script-approved-pilot-notes.docx`](./focus-group-script-approved-pilot-notes.docx) — the approved moderator script used to run each focus-group session: consent language, and the guiding questions and sub-questions on team formation, structuring, scaffolding, assessment and feedback, and teaming-pedagogy effectiveness, with notes from the pilot session.
- [`focus-group-preparation-prompts.docx`](./focus-group-preparation-prompts.docx) (also provided as [`.pdf`](./focus-group-preparation-prompts.pdf)) — the prompts sent to participants ahead of their session, so they could reflect beforehand. Includes the working definitions of *skills*, *values*, and *virtues* used throughout the study (skills: De Prada et al., 2022; values and virtues: Fowers et al., 2021).

See [`../../README.md`](../../README.md) for how the focus-group strand fits into the working group's overall methodology.
